아이폰 위젯 설치

아이폰은 웹페이지를 위젯으로 올릴 수 없습니다. 대신 Scriptable(무료)이 진짜 위젯을 그려 줍니다. 5분이면 됩니다.

  1. Scriptable 설치 App Store 에서 "Scriptable" 검색 · 무료
  2. 아래 버튼으로 스크립트 복사
  3. Scriptable 열고 오른쪽 위 + 누르기 빈 스크립트가 열립니다. 길게 눌러 붙여넣기
  4. 이름을 APEX 로 왼쪽 아래 설정(렌치) → Name 에 APEX
  5. 홈 화면에 위젯 놓기 홈 화면 빈 곳 길게 누르기 → 왼쪽 위 + → Scriptable → 크기 고르기
  6. 위젯을 길게 눌러 Edit Widget Script 에서 APEX 고르기 · When Interacting 은 Open URL 로 두면 눌렀을 때 APEX 앱이 열립니다
불러오는 중…

복사가 안 되면 위 상자를 길게 눌러 전체 선택 후 복사하세요.
위젯은 15분마다 스스로 갱신됩니다. 통신이 안 되면 마지막으로 받아 둔 일정을 씁니다.
