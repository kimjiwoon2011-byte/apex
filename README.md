# APEX — 모터스포츠 통합 알림

F1 · WEC · IMSA · DTM · GT3 일정과 소식을 한곳에서 보는 웹앱.

- `index.html` — 앱 전체 (HTML · CSS · JS 한 파일)
- `_redirects` — Netlify가 뉴스 RSS를 서버에서 대신 받아오는 설정 (브라우저 CORS 우회)

## 기능

- **마이홈** — 관심 시리즈·응원팀·응원선수를 고르면 팀 색과 실제 레이스카 사진으로 꾸며진 홈
- **소식** — 시리즈별 뉴스, 3일마다 자동 갱신, 제목 자동 번역
- **일정** — 캘린더, 서킷 지도, 경기 후 별점·리뷰
- **단톡방** — 가입 없이 들어가는 실시간 채팅
- **알림** — 다음 경기 카운트다운, 배경화면용 캘린더

한국어 · English · 日本語 지원, 라이트/다크 모드.

## 배포

빌드 과정이 없습니다. Netlify에 이 저장소를 연결하면 push할 때마다 자동 배포됩니다.

- Build command: 비워둠
- Publish directory: 저장소 루트

## 사진 출처

차량 사진은 위키미디어 커먼즈의 자유 이용 저작물입니다. 각 사진의 촬영자와 라이선스는 앱 화면 안에 표시됩니다.
