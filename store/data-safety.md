# 데이터 보안 설문 답변 (플레이 콘솔)

플레이 콘솔 → 정책 → 앱 콘텐츠 → **데이터 보안** 에서 묻는 것들입니다.
실제 코드를 확인하고 적은 것이니 그대로 답하시면 됩니다.

> 여기서 거짓으로 답하면 앱이 내려갑니다. 아래대로만 답하세요.

---

## 1. 데이터를 수집하거나 공유합니까?

**예** — 단톡방 기능 때문입니다.

## 2. 수집하는 항목

| 유형 | 항목 | 수집 | 공유 | 선택/필수 | 목적 |
|---|---|---|---|---|---|
| 개인정보 | **이메일 주소** | 예 | 아니요 | **선택** (단톡방 쓸 때만) | 계정 관리, 사칭 방지 |
| 개인정보 | **이름** | 예 | 아니요 | **선택** | 계정 관리 |
| 메시지 | **채팅 메시지** | 예 | 아니요 | **선택** | 앱 기능 |
| 사진·동영상 | **사진** | 예 | 아니요 | **선택** | 앱 기능 (단톡방에 올릴 때만) |

### 수집하지 않는 것 (모두 "아니요")

위치 · 금융정보 · 건강 · 연락처 · 통화기록 · 캘린더 · 기기 ID ·
광고 ID · 앱 사용 기록 · 검색 기록 · 설치된 앱 목록

## 3. 보안 관련 질문

| 질문 | 답 |
|---|---|
| 전송 중 암호화됩니까? | **예** (모두 HTTPS) |
| 사용자가 삭제를 요청할 수 있습니까? | **예** (앱 내 초기화 + 이메일 요청) |
| 데이터 수집이 앱 사용에 필수입니까? | **아니요** (단톡방을 안 쓰면 아무것도 수집 안 함) |
| 독립적인 보안 검토를 받았습니까? | **아니요** |

## 4. 근거 (검토자가 물어볼 경우)

- 구글 로그인은 **단톡방 탭에서만** 요구합니다. 소식·일정·마이홈은
  로그인 없이 씁니다.
- 로그인으로 받는 것은 **이메일과 이름뿐**이며, Supabase Auth 가 처리합니다.
  비밀번호는 앱이 보지 않습니다.
- 채팅과 사진은 Supabase 에 저장되며, 경기 종료 24시간 후 대화가 없으면
  자동 삭제됩니다.
- 광고 SDK 와 분석 SDK 가 **하나도 없습니다**. 코드에서 확인 가능합니다.
- 별명·설정·받아 둔 소식은 **기기 안에만** 저장되고 서버로 가지 않습니다.

## 6. 앱 접근 권한

플레이 콘솔이 "특별한 접근 권한이 필요한 기능이 있습니까?" 라고 물으면
**"모든 기능을 별도 절차 없이 사용할 수 있습니다"** 를 고르시면 됩니다.
(단톡방만 구글 로그인이 필요한데, 이는 검토자도 본인 구글 계정으로
바로 로그인해 확인할 수 있습니다.)
